# Student Performance Analysis Using PCA & K-Means

## Project Overview
This project uses machine learning techniques to analyze student data and identify patterns in student characteristics and academic performance.

## Objectives
- Perform exploratory data analysis (EDA).
- Preprocess and scale selected features.
- Reduce dimensionality using PCA.
- Group students using K-Means clustering.
- Visualize clusters and explore academic performance.
- Build an interactive dashboard using Gradio.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PCA (Principal Component Analysis)
- K-Means Clustering
- Gradio
- Google Colab

## Project Workflow
1. Load the dataset.
2. Perform exploratory data analysis.
3. Clean and preprocess the data.
4. Scale selected features.
5. Apply PCA to reduce dimensions.
6. Perform K-Means clustering.
7. Visualize the results.
8. Evaluate clusters using the Silhouette Score.
9. Create an interactive dashboard using Gradio.

## Results
- Dataset: 395 records
- Features used: 13
- PCA components: 2
- Clusters formed: 3
- Silhouette Score: 0.105
